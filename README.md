
# 📋 전체 요구사항 분석
### 1. **핵심 기능 흐름**

1. 프로그램 시작 → 파일에서 상품/프로모션 정보 로드
2. 상품 목록 출력 (프로모션 재고와 일반 재고 구분하여 표시)
3. 구매할 상품과 수량 입력받기
4. 프로모션 검증 및 추가 구매/정가 결제 확인
5. 멤버십 할인 여부 확인
6. 영수증 출력
7. 재고 차감
8. 추가 구매 여부 확인 (Y면 2번으로 돌아감)

### 2. **재고 관리 시스템**

- **두 가지 재고 타입**: 프로모션 재고 + 일반 재고
- 같은 상품이 두 줄로 표시 (프로모션 적용 상품 / 일반 상품)
- 구매 시 프로모션 재고 우선 차감
- 재고가 0이면 "재고 없음" 표시

### 3. **프로모션 시스템**

#### 프로모션 종류

- **탄산2+1**: 2개 구매 시 1개 무료
- **MD추천상품**: 1+1 (1개 구매 시 1개 무료)
- **반짝할인**: 1+1

#### 프로모션 규칙
- 날짜 체크 (start_date ~ end_date)
- 프로모션 재고 내에서만 혜택 적용
- 프로모션 수량 미달 시 추가 구매 유도
- 프로모션 재고 부족 시 정가 결제 안내

### 4. **할인 계산 로직**

### 시나리오 1: 프로모션 수량 미달
예: 콜라(2+1) 2개만 구매 시     
→ "1개를 무료로 더 받을 수 있습니다. 추가하시겠습니까?"      
→ Y: 3개로 변경 (2개 결제, 1개 무료)      
→ N: 2개만 구매 (프로모션 미적용), 프로모션 재고에서 차감       

### 시나리오 2: 프로모션 재고 초과
예: 콜라(2+1) 프로모션 재고 7개, 구매 10개       
→ 6개는 프로모션 적용 (4개 결제 + 2개 무료)       
→ "4개는 프로모션 할인이 적용되지 않습니다. 그래도 구매하시겠습니까?"       
→ Y: 10개 전체 구매 (6개 프로모션 + 4개 정가)
→ N: 6개만 구매

### 5. **멤버십 할인**
- 프로모션 미적용 금액의 30% 할인
- 최대 8,000원 한도
- 프로모션 할인 후 적용

### 6. **영수증 구성**
```
===========W 편의점=============       
상품명		수량	금액      // 실제 구매 수량과 금액     
===========증	정=============      
증정품목록          // 프로모션으로 무료 제공된 상품        
==============================      
총구매액		전체수량	전체금액   // 증정 포함 전체      
행사할인			-프로모션할인액        
멤버십할인		-멤버십할인액     
내실돈			최종결제금액              
```

### 7. **입력 검증 및 에러 처리**

- 형식 오류: `[상품명-수량],[상품명-수량]` 형식 검증
- 존재하지 않는 상품
- 재고 초과
- Y/N 입력 검증

### 8. **재고 업데이트 규칙**
- 프로모션 재고 우선 차감
- 프로모션 재고 소진 시 일반 재고 차감
- 다음 구매 시 업데이트된 재고 표시
